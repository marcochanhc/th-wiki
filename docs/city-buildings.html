簡介與閱讀說明

正文只根據遊戲資料表與官方字串，不評定建築強弱，也不排升級優先。本頁寫主城城建與升級排程。這不是城堡外觀；城堡外觀見已發佈的城堡外觀總表。這不是裝飾物；裝飾物見已發佈的裝飾物總表。魔獸祭壇見已發佈的守護魔獸總表。帕魯營地見已發佈的帕魯總表。寵物樂園見已發佈的寵物總表。秘寶大廳見已發佈的秘寶總表。主表 id 151 顯示名為「商隊」，只在名錄與升級索引中照錄，不展開商隊系統。

  • 顯示名、說明按該列 name／des 鍵從字串表照錄。名稱鍵不一定是 citybuilding_name_{id}。例如 id 106 的名稱鍵是 citybuilding_name_6，id 155 與 140 都用 citybuilding_name_140。id 111 的顯示名原文是 <color=#00000000>XXX</color>，照錄；該列 des 欄為空（不是缺 citybuilding_des_111 這條鍵）。說明鍵在字串表沒有內容者標明「字串表沒有內容」。不編造沒有官方名的資源或道具。
  • 官方用語是「部族」。例如「部族雕像」「部族兵營」皆照錄。建築名「功勳碑」出自 citybuilding_name_168（「勳」為 U+52F3）；說明 citybuilding_des_168 寫「持續產出勛章，最多可儲存12小時。」（「勛」為 U+52DB）。村民提示 building_villager_tips_168 寫「勛章產量+{0}/h」。兩種用字並存，不統一。
  • 兩張升級表並列，不以其中一張覆寫另一張。名錄的等級上限先照錄主表 maxlevel／new_maxlevel；升級列的等級範圍、消耗、時間與前置若兩表不同，分開標明來源。只在兩表相同時才合寫。
  • 不要把 show_type=2 轉成百分比。官方說明若已有百分比字串，只照錄該字串，與表上原值並列。season、kvk_theme_dic、server_list、theme 只照錄，不對成 S2／S3，不自行加上開放狀態。類型 999 的各段沒有官方資源名，只錄原值。buildTime 沒有單位欄，不自行標成秒或分鐘。

名錄

主表 citybuilding.json 共 126 列，id 從 101 到 201，彼此不重複。count 皆為 1。is_discard 為 1 的有 33 列，其餘 93 列為 -1。is_building_list 為 1 的有 73 列，為 -1 的有 52 列，為 0 的只有 id 181（城牆）。initlevel 為 0 的有 122 列，為 1 的有 4 列。type 沒有官方中文類型名。new_type 僅 id 114（鐵匠鋪）為 4，其餘為 -1。114 也是唯一 maxlevel（1）與 new_maxlevel（40）不同的列。

lvupid 等於自身 id 的有 117 列。其餘 9 列與另一座建築共用升級索引：135 集結大廳用 133（特權隊列）；13702 倉庫·二用 137（倉庫）；156 英雄雕像用 151（商隊）；180 磨石工坊·二用 175（磨石工坊）；307 靈息古木·二用 301（靈息古木）；308 煉鐵工坊·二用 303（煉鐵工坊）；309 磨石工坊·二用 305（磨石工坊）；198 育藻池·二用 196（育藻池）；201 浮石礦場·二用 199（浮石礦場）。其中 id 309 的名稱鍵是 citybuilding_name_180。升級表裡仍有這些建築自身 index＝其 id 的列，但對應建築的 lvupid 並不指向那些列。

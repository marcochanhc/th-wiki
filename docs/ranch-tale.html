簡介與閱讀說明

官方總名是「牧場物語」。規則標題是「牧場物語活動說明」。界面圖鑑分頁是「帕菲圖鑑」，與本頁所寫的整套玩法範圍不同，兩詞不合併。分頁與功能名還有「牧場」「尋覓」「商店」「聲望」「我的牧場」「牧場聲望」「交易所」「牧場商店」。

貨幣官方短名是「牧歌金幣」，說明：「牧場通用的交易貨幣，印有帕菲圖案。用於購買帕菲球、牧場設施及獎勵。」。食物官方短名是「帕菲起司」，說明：「香噴噴的點心，沒有帕菲能拒絕！每次投餵可增加100點飽足感。」。界面另有「牧場代幣」「牧場金幣」「金幣」等用字，與「牧歌金幣」並列，不合併。說明中的「收藏憑證」與「收藏券」也並列，不合併。

城建與同盟裡若也有「牧場」這個詞，與本系統分頁不是同一處，不合併，也不把城建升級排程搬進來。品質欄沒有官方顏色名，只錄表上原值。

官方說明

牧場物語活動說明

說明頁的分節標題是「活動背景」、「帕菲」、「拜訪」。

隨著雲海航路逐漸恢復，各城邦的商隊再次啟程。領主們在一座廢棄貿易站附近，發現了一片沉寂已久的空中牧場。
這裡曾是四大城邦共同建立的帕菲培育基地，負責照料遷徙途中的帕菲，並為遠行商隊提供食物、材料與航行幫助。黯風出現後，航路被迫中斷，牧場逐漸荒廢，生活在此的帕菲也散落到了雲海各處。
如今風力趨於平穩，越來越多的帕菲重新出現在碎島、浮城和貿易站附近。為了讓牧場恢復往日生機，四大城邦共同成立“萬風牧會”，邀請領主尋找帕菲，將它們帶回牧場照料和培養。
成長後的帕菲可以持續產出金幣，領主也可以將帕菲野放至萬風牧會旗下的“帕菲之家”，根據其成長階段與特殊特性獲得金幣回報。四大城邦還會不定期舉辦“帕菲盛典”，為表現優異的領主授予“帕菲大師”的榮譽稱號。

尋找帕菲

1. 領主可前往被佔領的碎島、浮城和風堡等遺跡，在棲息地中尋找帕菲。
2. 在其他公會佔領的遺跡中尋找時，帕菲有一定機率會受到驚嚇並溜走。逃走的帕菲會為佔領該遺跡的公會留下一份公會禮物。
3. 每次尋找都需要消耗一個帕菲球。帕菲剛進入帕菲球時，會因為初次見面而緊張地不停跳動。領主需要跟隨帕菲球的晃動完成若干次律動考驗：
--動態環進入目標環時點擊，即可完成一次律動。
--點擊位置越貼近目標環，單次獲得的律動值越高。
--每次律動獲得的分數將累積為該帕菲的最終律動值。
--律動值不會影響帕菲的種類或稀有度，但會在“帕菲盛典”等活動中作為重要評選標準。
4. 首次找到某種帕菲時，將自動解鎖對應圖鑑。

帕菲培養

【成長】
1. 帕菲初次來到牧場時處於“幼崽期”。只要沒有進入飢餓狀態，它就會隨時間累積成長進度，直到進入“成年期”。
2. 成年期的帕菲不再累積成長進度，並開始持續為牧場產出金幣。
【飽足感】
1. 每隻帕菲都擁有獨立的飽足感，用於維持成長與金幣生產。
2. 帕菲每秒消耗1點飽足感。飽足感下降至5%時，將進入飢餓狀態。飢餓狀態下，幼崽期會暫停成長，成年期會停止產出金幣。
3. 領主可使用金幣購買食物，並透過投餵恢復帕菲的飽足感。記得經常回來看看，別讓牧場裡的小傢伙餓著肚子等待太久。
【特性變化】
1. 部分高稀有度帕菲會在成長過程中形成特殊特性。特性不會改變帕菲的基本種類，但會讓它擁有更高的野放價值。
2. 紫色(含)以上稀有度的帕菲可以發生特性變化。紫色帕菲最多擁有1個特性。橙色帕菲最多擁有2個特性。
3. 從幼崽期至成年期的過程中，成長進度達到20%、40%、60%、80%和100%時，都會進行一次特性變化判定。每個成長節點均有10%的機率獲得新特性。好友來祝福時，也有機率幫助帕菲獲得新特性。
4. 每種特性只會出現一次，已經擁有的特性不會重複獲得。
5. 不同特性會為野放收益提供不同倍率的加成。當帕菲同時擁有兩個特性時，兩項收益倍率將相乘計算。

帕菲產出

【持續產出】
1. 成年期帕菲在飽足狀態下，會隨時間持續產出金幣。
2. 產出的金幣會暫時儲存在帕菲身上。每隻帕菲都有獨立的金幣儲存上限。達到儲存上限後，帕菲將無法繼續累積金幣。
3. 進入飢餓狀態後，金幣產出會立即暫停。
4. 領主與帕菲互動後，可以一次領取它目前儲存的全部金幣。記得定期與帕菲互動，既能增進感情，也能避免金幣存滿後停止產出。
【野放價值】
1. 領主可以將牧場中的帕菲野放至萬風牧會旗下的“帕菲之家”，由牧會為它安排更加適合的生活環境。
2. 幼崽期和成年期帕菲的野放收益不同，萬風牧會更青睞已成長的帕菲。
3. 帕菲擁有特性會提高野放收益，同時擁有兩個特性時，兩項特性的加成倍率相乘計算。
為了保證牧場能夠持續產出金幣，野放時請至少保留一隻帕菲。
領主可以前往其他領主的牧場，與好友培養的帕菲互動。拜訪行為分為“祝福”和“打招呼”。
每位領主每天可以接受祝福和打招呼的次數都有限制。達到上限後，當日將無法繼續對其帕菲進行互動，因此記得多去不同領主的牧場串門子。

祝福

拜訪好友牧場時，可以為好友的帕菲送上祝福。
1. 給好友的帕菲祝福有機率幫助其獲得新的特性。
--為幼崽期帕菲祝福，可以縮短其剩餘成長時間。
--為成年期帕菲祝福，可以立即為它增加一筆金幣。
2. 每位領主每天擁有一定的祝福次數。已使用的祝福次數會在次日恢復一定數量。

打招呼

拜訪好友牧場時，還可以與帕菲打招呼。
1. 帕菲心情不錯時，會將自己身上40%的金幣作為見面禮送給來訪者。
2. 每位領主每天擁有一定的打招呼次數。已使用的打招呼次數會在次日恢復一定數量。
3. 當帕菲身上的金幣不足時，無法繼續透過打招呼獲得金幣。
多去不同牧場拜訪，和各式各樣的帕菲打個招呼，也許它們會為你準備一份小小驚喜。

上列打招呼說明寫了 40%。設定表另有一個原值 20。兩者並列照錄，不自行取捨哪一個才算顯示規則。

交易所說明寫分潤「10%」，設定表對應原值是 10，兩者可對看，仍只照錄。

交易所

交易所

1. 牧場聲望達一定等級後解鎖交易所，可在自己的牧場使用牧場金幣購買帕菲的收藏憑證。
2. 每購買1份收藏憑證消耗1點購買次數。購買次數有上限，每日恢復一定數量，上限和恢復量隨牧場聲望等級提升。
3. 您持有的收藏憑證可在自己或其他領主的牧場出售。不同領主的牧場中，同一收藏憑證的報價可能有所不同，價格也會隨日期變化。
4. 出售後立即獲得該牧場目前報價對應的牧場金幣。請留意購入成本，交易可能獲利，也可能虧損。
5. 在其他領主牧場出售收藏憑證時，牧場主人可額外獲得10%的交易分潤（每筆最低1金幣），不會減少您的出售收入。每日可領取的交易分潤有上限。
6. 牧場主人需及時領取分潤，逾期將無法領取。

交易所商品表有 6 列。其中 2 列可對上官方收藏券名稱；其餘 4 列沒有可靠的官方短名，不靠後綴或順序去對。字串表另有更多「收藏券-…」名稱，未對上表列的只存在字串表，不補進名錄。
